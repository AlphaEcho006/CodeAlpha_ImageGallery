# CodeAlpha Image Gallery

A responsive image gallery built with HTML, CSS and JavaScript as part of my CodeAlpha Frontend Development internship (Task 1).

**Live demo:** https://alphaecho006.github.io/CodeAlpha_ImageGallery/

## Features
- Responsive grid that adapts to desktop, tablet and phone screens
- Lightbox viewer with next, previous and close buttons
- Keyboard controls (left and right arrows to browse, Esc to close)
- Swipe support on touch devices
- Category filters: All, Cars, Anime and Food
- Hover effects with zoom, title overlay and mint glow
- Smooth transitions, staggered entrance animations and loading shimmer
- Dark mode design with a mint green accent

## Tech Used
HTML, CSS, JavaScript (no frameworks)

## How to Run
Open `index.html` in your browser, or use the Live Server extension in VS Code.
